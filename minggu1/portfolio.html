Tiramisu: File Encryption (PBL Semester 1)

Aplikasi enkripsi file pakai AES-256-GCM dengan kunci dari Argon2id. File diproses per potongan 384 KB, jadi file besar pun aman tanpa makan RAM. Skemanya envelope encryption: kunci file dibungkus lagi pakai kunci master. Ada juga versi server yang langsung upload hasil enkripsi lewat SFTP.

A file encryption app built on AES-256-GCM with Argon2id key derivation. Files are processed in 384 KB chunks, so big files stay safe without eating RAM. It uses envelope encryption: a per-file key wrapped by the master key. A server version uploads the encrypted output over SFTP.

  • Python
  • PyQt6
  • PyCryptodome
  • Argon2
  • Paramiko / SFTP

NetEye: Network Monitoring Console (PBL Semester 2)

Toolkit monitoring LAN buat PBL Rekayasa Keamanan Siber. Awalnya versi desktop (PyQt6, dashboard ala SOC, port scanner multithread), terus saya kembangin jadi versi web: login, dashboard, scanner berbasis nmap dengan progres realtime, web terminal, dan allowlist target biar tetap sesuai etika dan UU ITE.

A LAN monitoring toolkit for the Cyber Security Engineering PBL course. It started as a desktop app (PyQt6, SOC style dashboard, multithreaded port scanner) and grew into a web version: login, dashboard, nmap based scanner with realtime progress, a web terminal, and a target allowlist to stay within ethics and Indonesian IT law.

  • Python
  • Flask
  • Nmap
  • PyQt6
  • Docker
  • Kali Linux

Velvet: Wordlist Generator

Generator wordlist yang saya bikin buat belajar social engineering: gimana orang biasanya nyusun password dari nama, hobi, tanggal lahir, atau kota. Bisa kombinasi kata kunci, variasi huruf besar kecil, leetspeak, dibalik, sampai pola tanggal. Cuma buat belajar, dan dipakai di lingkungan yang memang diizinkan.

A wordlist generator I built to study social engineering: how people usually build passwords from a name, hobby, birth date, or city. It combines keywords, case variants, leetspeak, reversals, and date patterns. For learning only, in authorised environments.

  • Python
  • PyQt6
